# Changelog

## 1.3.0 — 2026-10-18

- Accept legitimately disabled external form controls without weakening owned lesson-input checks; stop counting empty file inputs against the actual-upload limit; ignore unrelated form POSTs while retaining oversized-body protection.
- Compare teaching JSON with strict scalar types and canonical object keys across editor, validation and restoration. Batch retained-history preparation per field-list save, reject non-figure file IDs and bind revision signatures to private key, salt, account and node context.
- Reject an obsolete reading identity when a modified older private revision replaces newer published teaching; preserve native immutable restores with fresh versions.
- Complete optional explicit equation labels and install/update a noncropping, no-upscale diagram style while preserving operator configuration and original links.
- Add optional paired practice variant identifiers to the existing component model; no question-bank lookup, entity or scoring.
- Use S consistently in new demonstration text and original diagrams. Document inline TeX, configuration import order, pilot content boundaries and the required update 11001. Preserve existing content, revisions and UUIDs; no Paragraphs work.

## 1.2.0 — 2026-10-18

- Guard published lessons against losing their chapter through outline removal, clearing the chapter role or chapter deletion; provide an explicit authorized unpublish action before moving lessons.
- Protect pending managed adoption behind ordinary Resource defaults, including stale native edits and defensive storage writes, while retaining ordinary legacy saving.
- Keep chapter publication under native Drupal or the site's moderation workflow, with an explicit in-form notice about public order changes.
- Attach existing flat figure components to an example/practice prompt, hint, answer or solution; preserve managed files, UUID anchors, revision history and print disclosure behaviour.
- Add focused native/browser regressions and manuscript identity/asset guidance. Existing content is preserved without a database schema migration. No Paragraphs dependencies, implementation or migration.

## 1.1.0 — 2026-10-17

- Add optional shared Layout Builder presentation for published managed chapters and lessons, using one complete reader plus supported supplementary content blocks and menus.
- Require explicit per-display activation; preserve existing fields, layouts, overrides, lesson storage, historical revisions, files and progress.
- Keep private previews, historical views and dedicated Study/Print on the existing reader. Protect managed content from an alternate per-node layout-save workflow.
- Add container-aware optional styling and native/default-layout regression coverage. Paragraphs remains deferred to a later project phase.

## 1.0.3 — 2026-10-17

Corrective release following the independent review of 1.0.2:

- Protect complete native-form submissions against input/body truncation; bound new native-editor content to 120 components across all steps and report actual server capacity. Existing stored documents and native numeric reordering are retained.
- Leave empty lesson fields empty on ordinary Notes/Assignment resources.
- Allocate restored/reintroduced step versions above retained history, preserving learner revisit accuracy and stable UUIDs.
- Share meaningful-content checks between publication and workbench readiness; preflight required learning-path choices through callback-aware Drupal APIs.
- Keep generated absolute reader URLs intact and let individual figure alternative text name full-resolution links.
- Correct explicit-dark print palettes, matching-root Drupal behavior attachment, and missing/blocked MathJax fallback notices. Version changed browser integrations for cache refresh, while retaining the bundled MathJax 4.1.3 assets.
- Retain focused native/browser regressions and provide a repeatable isolated test/CI entry point. No new lesson component types, assessments or grading features.


## 1.0.2 — 2026-10-17

Publish the standalone Drupal module at `actools-pl/lesson_module`, with installation, BOA deployment, editor, operations and contributor guidance. Integrate the current `actools_bs5` sticky header through a scoped compatibility adapter that defers to the theme's native offset contract. Preserve secondary authoring controls when the theme adds Bootstrap primary styling. No database schema change; existing content, revisions, IDs and progress are retained.

## 1.0.1 — 2026-10-17

Focused product review: separate Core/Optional routes, compact mobile navigation, consistent reading/figure measures, conditional persistent desktop outline, semantic orientation lists and one private accessible reading meter. Guided reading has one primary action; Read all changes only explicitly selected step marks.

Authoring gains a numbered outline, retained section state, action focus, hidden-error recovery and independent duplicate-component editing. Native Save draft preserves public content; explicit reviewed publication, revision snapshots and latest-draft access checks protect editing. The workbench shows assignment, readiness and pending state. Existing core Content Moderation remains authoritative. Existing content, UUIDs, revisions and progress are retained; upgrade requires cache rebuild, not a reinstall.

## 1.0.0 — 2026-10-17

First installable release of Actools Lessons: module-owned guided reader and chapter landing page; separate lesson/step navigation; native revision-owned structured authoring; eight component types; local mathematical typesetting; continuous/print views; explicit private progress and resume; compatible Topic/Resource setup; optional original Surface Tension example; actual Drupal tests.

Implementation decision: core-only custom structured field rather than new Paragraphs dependencies. Stable step/component identities and full native node revisions preserve the future migration boundary. Existing themes, starter recipes, role grants, taxonomy seeds and legacy resources are not silently changed.
